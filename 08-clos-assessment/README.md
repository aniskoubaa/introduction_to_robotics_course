# 08 — CLOs Assessment

**Status:** ❌ Completed at end of semester.

Direct measurement of the four CLOs, at **question level** — not whole-instrument level. Each
exam and assignment question is tagged with one CLO; attainment is computed from the tagged
item sets.

| CLO | Evidence base |
|---|---|
| CLO 1 — EXPLAIN | Quizzes, Midterm I explain-section, Final explain-section |
| CLO 2 — ANALYZE | Assignments, Midterm I & II analyze-sections, Final analyze-section |
| CLO 3 — DEVELOP | Weekly ROS 2 deliverables, Assignments 1–4, project implementation and demo |
| CLO 4 — EVALUATE | Project report, project presentation, peer evaluation, final-exam ethics question |

## Deliverables

| File | Description |
|---|---|
| `ee414-fcar-fall2026.xlsx` | FCAR sheet — attainment per CLO against the target |
| `ee414-question-clo-map-fall2026.csv` | Every question ID → CLO → marks → cohort mean |
| `ee414-clo-attainment-analysis.md` | Interpretation, and the action taken on any CLO below target |
