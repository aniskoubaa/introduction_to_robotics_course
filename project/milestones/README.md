# Project Milestones

| # | Milestone | Week | Deliverable | Weight |
|---|---|---|---|---|
| M0 | Team formation | 4 | Three names, one repository, one nominated coordinator | — |
| M1 | Proposal | 5 | 2 pages: scope, architecture sketch, division of work, risks. **Approval required to proceed.** | 3% |
| M2 | Design review | 13 | 10-minute supervised walkthrough: what runs today, what is left, what is blocked | 3% |
| M3 | Demonstration | 14 | Live run + 10-minute presentation + individual questions | 8% |
| M4 | Report and repository | 14 | 6-page report, final repository, peer evaluation forms | 6% |

**Individual questioning at M3 is not optional.** Each member answers on a part of the system
they did not personally write. It is the only reliable check that CLO 3 was met by the team
rather than by one member.
